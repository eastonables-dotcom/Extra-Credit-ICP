## 🎵 Adding Background Music

To add your own background music:

1. **Prepare your audio file:**
   - Convert to MP3 format (recommended) or OGG
   - Keep file size reasonable (< 5MB for web performance)
   - Use instrumental music that loops well

2. **Name your file:**
   - Save as `music.mp3` or `music.ogg`
   - Place it in the same folder as `index.html`

3. **Alternative: Use a URL**
   - Edit the audio element in `index.html`:
   ```html
   <source src="https://example.com/your-music.mp3" type="audio/mpeg">
   ```

4. **Music Controls:**
   - Click the "🔊 Music" button in the top-left HUD
   - Music will start after your first interaction with the page
   - Volume is set to 30% by default

## 🚀 How to Play

- **Arrow Keys**: Move left/right
- **Space/Up Arrow**: Jump
- **Enter**: Start game from title screen
- **Escape**: Return to home screen
- Reach the portal to complete each level!
