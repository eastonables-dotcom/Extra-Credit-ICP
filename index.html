How This Game Was Built

This game was built as a single-file HTML project using HTML, CSS, and JavaScript.


Features Included

  • Vocabulary question randomization
  • Dynamic scoring system
  • Visual feedback for right and wrong answers
  • Win condition system
  • Modal information panel
  • Animated background stars
  • Level select home screen
  • Respawn challenge system
  • Portal and death animations

Programming Concepts Used

  • Arrays to store vocabulary
  • Objects to organize data
  • Functions to manage gameplay
  • Event listeners for interaction
  • Canvas drawing for graphics
  • Conditional statements to check answers
